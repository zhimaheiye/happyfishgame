# docs/workflows/atlas-collection.md：游戏图鉴采集工作流

> 本文档沉淀《开心水族箱》游戏内大图鉴（4331 总量）的 UI 结构、交互坐标、全自动化采集流程与异常容错规范。  
> 目的是让任何自动化脚本或新接手 Agent 无需重新摸索 UI 规律。

---

## 一、图鉴 UI 结构与交互特征

### 1. 基础环境与规格
- **分辨率**：固定横屏 `1920 x 1080`。
- **底层引擎**：基于 Cocos2d-x 渲染，无原生 Android 控件树（uiautomator 无法捕获游戏内组件），必须依赖 **ADB 坐标交互 + 截图视觉识别/OCR**。

### 2. 界面层级与入口辨析
1. **千鱼收集**：主界面右侧顶层气泡图标（蓝皮书+星星）打开的是以章节（1/2/3/4/11）为单位的“邮票式集邮活动”，**并非包含 4331 条鱼的全局大图鉴**。
2. **全局大图鉴（4331 Atlas）**：
   - 顶部标有：`收集进度 XX% XXXX/4331`；
   - 顶部包含搜索输入框与【标签查找】按钮；
   - 顶部第 6 个 Tab 为金黄色带星图鉴书图标；
   - 右侧包含纵向快速跳转导航栏：标有 `1`、`100`、`200`、`300`、`400`... 区段锚点。

### 3. 图鉴卡片网格布局（1920x1080 坐标参考）
每屏展示 **2 行 × 6 列**，共 12 个主卡位：
- **行 1 中心纵坐标**：约 `Y ≈ 410`
- **行 2 中心纵坐标**：约 `Y ≈ 700`
- **各列横坐标分布**：
  - Col 1: `X ≈ 230`
  - Col 2: `X ≈ 510`
  - Col 3: `X ≈ 790`
  - Col 4: `X ≈ 1070`
  - Col 5: `X ≈ 1350`
  - Col 6: `X ≈ 1630`
- **右侧区段跳转栏**：`X ≈ 1790`
- **左上角返回按钮**：`X ≈ 90, Y ≈ 65`

### 4. 详情弹窗结构
点击任意鱼卡片（已拥有或未拥有）均会弹出居中半透明水泡详情弹窗：
- **左上方**：鱼动态插画及收藏心标；
- **右上文本区**：
  - 第一行：鱼名（大字，如“小丑鱼”）；
  - 第二行：类别标签（如“真实鱼”）；
  - 第三行：特点描述（如“活泼，好动”）；
- **参数区域**：
  - `产宝时间：` （如 15秒）；
  - `皇冠时间：` （如 60分钟）；
  - `获得来源：` （包含小图标及胶囊按钮/文本，如“商店购买”）；
- **底部奖励物展示**：贝币、经验数值及产出宝物图标；
- **弹窗关闭机制**：点击弹窗外空白区域（如 `X: 960, Y: 150`）或左上角返回，即可关闭详情且**列表滚动位置不会丢失**。

## 二、标准自动化采集闭环流程

```text
[当前图鉴位置]
       │
       ▼
   [定位鱼卡] ────> 点击卡片坐标 (X, Y)
       │
       ▼
  [详情弹窗展现]
       │
       ├────> 1. 截取全屏原始图保存至 raw/screenshots/{filename}.png
       │
       ├────> 2. OCR / 视觉模型提取关键字段:
       │         - name
       │         - category_tag
       │         - description
       │         - produce_time_raw
       │         - crown_time_raw
       │         - acquisition_raw (原文强保留)
       │
       ├────> 3. 标准化转换 (produce_time_seconds, acquisition_type, availability)
       │
       ├────> 4. 追加写盘: data/fish.jsonl
       │
       ├────> 5. 点击遮罩空白区关闭详情弹窗
       │
       ▼
[更新 checkpoint] ───> 写入 checkpoints/progress.json
       │
       ▼
  [推进至下一条]
```

## 三、异常跳过与容错规程

1. **单条识别存疑**：
   - 绝不挂起整体循环。
   - 保存当前截图至 `raw/screenshots/unresolved_{index}.png`。
   - 向 `unresolved/unresolved.jsonl` 登记问题类型（如“获取来源文字模糊”）。
   - 关闭弹窗，继续下一条。
2. **点击未响应 / 未弹窗**：
   - 重试点击一次（延迟 500ms）。
   - 若仍未弹窗，记录异常位置至日志，跳至相邻下一个坐标，避免死锁在同一卡位。
3. **意外退出图鉴**：
   - 捕获主屏特征，执行恢复流重新进入大图鉴，并根据 `checkpoints/progress.json` 快速跳回对应区段。

## 四、已验证的重要工程结论

- **列表状态保持**：从卡片详情弹窗返回后，大图鉴的滚动条与偏移量保持原位，不需要从头重新翻页。
- **未拥有鱼类同样支持详情查看**：无论玩家是否收集该鱼，点击卡片均可调出完整的获取途径与产宝信息，具备完整可采性。
- **右侧导航区段精准有效**：点击 `100`、`200`、`300` 等右侧锚点可迅速对齐大区段，极大缩减滑动翻页误差。
